# Ground-truth review guide

The expanded benchmark is generated by `evaluation/build_ground_truth.py` and
contains 150 bilingual questions across ten intent families. Every row is
deliberately marked `seeded_pending_human_review` until a reviewer confirms the
relevant document IDs.

## Review workflow

```bash
make export-review
```

Open `evaluation/ground_truth_review.csv` and inspect each question against the
source passages in `data/docs/`. Keep the proposed IDs when they fully support
the question; add a second ID for questions that genuinely require multiple
sources. Remove an ID when it is only topically related but does not support
the claim. Record uncertainty or an unanswerable question in `notes`.

Fill `reviewed_relevant_document_ids` as a comma-separated list, set
`review_status` to `reviewed`, and add reviewer name/date. Then apply and
validate the decisions without changing the seeded source file:

```bash
uv run python -m evaluation.review_ground_truth \
  --apply evaluation/ground_truth_review.csv \
  --reviewer YOUR_NAME \
  --output evaluation/ground_truth_reviewed.jsonl
uv run python -m evaluation.validate_ground_truth \
  --input evaluation/ground_truth_reviewed.jsonl
```

For source-apportionment questions, confirm that the answer distinguishes an
emissions inventory from receptor/source-apportionment evidence. For policy
questions, confirm instrument type and status. For exposure and high-rise
questions, confirm that the cited source supports advice and limitations rather
than a universal medical or floor-height claim.
