# Indonesian ISPU categories
Publisher: Ministry of Environment and Forestry
Source: https://peraturan.bpk.go.id/Details/163466/permen-lhk-no-14-tahun-2020

The Indonesian ISPU categories used in this demo are Baik (1-50), Sedang
(51-100), Tidak Sehat (101-200), Sangat Tidak Sehat (201-300), and Berbahaya
(301 or higher). ISPU is an index without a physical concentration unit.

Never describe an ISPU value as a PM2.5 concentration. The application should
show the index and the concentration separately.
